## 2026-07-27 - [Fix N+1 and Concurrency Bugs in Blazor Server Data Fetching]
**Learning:** Using `Task.WhenAll` to execute concurrent database queries (e.g., `UserManager.FindByIdAsync` or `DbContext` queries) within a Blazor Server component causes EF Core concurrency exceptions (`InvalidOperationException: A second operation was started on this context instance before a previous operation completed`). This occurs because Blazor Server scopes the `DbContext` per circuit (connection), and EF Core does not support multiple concurrent operations on the same context instance. Additionally, using `Task.WhenAll` inside a loop leads to severe N+1 performance bottlenecks.
**Action:** When fetching related data in Blazor Server, avoid `Task.WhenAll` for DbContext operations. Instead, batch queries using `.Contains()` (e.g., `Users.Users.Where(u => ids.Contains(u.Id)).ToDictionaryAsync()`) to fetch data in a single roundtrip, or eager-load related entities using `.Include()` (e.g., `db.Entities.Include(e => e.Children)`).
